# Метрики тестирования агента по поиску информации в интернете

strict hit@1 - ответ дословно виден в выдаче
strict hit@3 - ответ дословно виден в выдаче
retrieval hit@3 - ответа в выдаче нет но его можно найти через WebFetch
retrieval hit@1	- ответа в выдаче нет но его можно найти через WebFetch
MRR	- правильный ответ в самом верхнем пункте из выдачи 
Средний P@3	- выдача по теме или нет
Средняя свежесть - выдача результатов актуальная по дате, в пределах 30 дней
