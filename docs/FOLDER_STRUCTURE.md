## 🤔 Почему в проекте ДВЕ папки "src"?
Программа построена на технологии **Tauri**. Tauri склеивает две разные технологии в одну программу:
1. **Frontend (Папка `src/`)** — Это "Лицо" приложения. Окошки, кнопки, цвета и анимации.
2. **Backend (Папка `src-tauri/`)** — Это "Двигатель". Он работает с жестким диском, загружает ИИ-модели в видеокарту и делает тяжелые вычисления. Внутри нее есть своя папка `src` (код двигателя).

Ниже приведено полное описание всех папок в проекте.

## 📁 Корневые папки проекта

- **`agents/`** — Ваша "команда" ИИ-агентов.
  - Файлы `.md` (Markdown) — Инструкции, характеры и правила общения конкретных агентов.
  - Подпапки `workflows/` с файлами `.yaml` — Схемы диалогов (графы). Определяют, какой агент за каким вступает в разговор. Выглядят как визуальные схемы во вкладке "Студия агентов -> Граф".
  - Папка `media/` — Агенты изображений: `backend/image_generator.md` (генерация с нуля) и `backend/image_editor.md` (правка прикреплённых картинок), граф `transitions/media-flow.yaml` (выбор генерация/правка). Картинки рисует движок изображений (см. Настройки).
- **`docs/`** — Документация проекта (включая этот самый файл).
  - `GUI_TESTING.md` — Как ИИ-агент может сам тестировать интерфейс программы (нажимать кнопки и проверять результат) через отладочный порт WebView2.
- **`test_cases/`** — Файлы с тестовыми вопросами. Используются во вкладке "Тест агентов ИИ", чтобы автоматически прогнать сотни вопросов через агента и проверить, как он отвечает.
- **`src/`** — Папка Лица (Интерфейса). Подробности ниже.
- **`src-tauri/`** — Папка Двигателя и системных настроек. Подробности ниже.

## 🎨 Лицо приложения: папка `src/`
Здесь находится всё, что отвечает за визуальную часть.

- **`controllers/`** — Управляющие вкладками. Они ловят ваши клики:
  - `chat.ts` — Контроллер ОДНОЙ чат-вкладки (вкладок может быть несколько). Поле ввода,
    кнопки отправки, выбор файлов и папок, перетаскивание файлов из Проводника, показ мыслей агентов,
    стриминг, черновик. Содержит `ChatTabState` (пер-tab стейт) и роутинг событий движка
    (`onProgress/onStatus/onStreamChunk/...`) + module-scope `activeProcessingChat` (обработка строго последовательная).
  - `chat-router.ts` — Глобальные Tauri-события движка/агентов, регистрируются ОДИН раз:
    перенаправляют в обрабатывающую вкладку (`download_progress` логируется глобально).
  - `tabs.ts` — Контроллер браузерных вкладок (`TabController`): полоса вкладок, создание
    «+», закрытие (последняя → авто-новая main), drag по оси X, ПКМ-меню (переименовать/
    копировать/проводник/удалить), глобальное меню по кнопке `☰` (новая вкладка и разделы
    приложения), персистентность в `app_config.json` (`set_tabs`).
    Разделы sessions/agent-studio/logs — синглтон, settings/engines — дубли делят
    один живой узел без клонов; навигация из «Настройки» — `openSectionInPlace`
    (в той же вкладке); `activate` держит инвариант «ровно один видимый» с логом.
    Сессии неактивных вкладок и тяжёлые панели движков загружаются лениво.
    Также `getActiveChatController` / `getChatControllerForSession` + `TAB_REGISTRY`.
  - `sessions.ts` — Раздел «История сессий» (открыть/копировать/удалить сессию).
  - `settings.ts` — Раздел «Настройки» (ползунки, каталоги моделей, переводчик). Читает
    активную вкладку через `getActiveChatController()` для параметров выбранной модели.
  - **`graph/`** (папка) — Редактор графов. Рисование блоков и соединение их стрелочками.
    - `index.ts` — «Дверь» редактора графов. Собирает все части в один контроллер.
    - `graph-class.ts` — Каркас контроллера (поля, кнопки, горячие клавиши).
    - `types.ts`, `constants.ts` — Типы и настройки внешнего вида блоков (цвета, названия узлов).
    - `canvas-part.ts` — Холст: выделение, рамка выбора, перетаскивание нескольких блоков разом.
    - `nodes-part.ts` — Добавление, копирование, переименование блоков.
    - `panel-part.ts` — Правая панель редактирования параметров выделенного блока.
    - `edge-part.ts` — Стрелочки-связи: создание, перетаскивание, переподключение.
    - `flows-part.ts` — Открытие и сохранение схем (YAML-файлы графов).
    - `history-part.ts` — Кнопки "Отменить"/"Вернуть" и индикатор несохранённых изменений.
    - `menu-part.ts` — Контекстное меню (клик правой кнопкой мыши по блоку).
    - `lifecycle-part.ts` — Запуск и переключение вкладок.
    - `switch-logic-part.ts`, `node-html.ts`, `layout.ts` — Внутренняя логика блоков-переключателей,
      отрисовка содержимого блока и автоматическая раскладка схемы.
  - `agent-test.ts` — Вкладка автоматического тестирования агентов.
  - `coding-test.ts` — Тестирование кодинг-способностей LLM.
- **`ui/`** — "Художники". Рисуют мелкие детали интерфейса:
  - `render.ts` — Рисует облачка сообщений (ваши и от ИИ).
  - `image-attachment.ts` — Рисует картинку в сообщении: открывает большую версию и сохраняет картинку кнопкой на её углу. Для вложения-пути загружает миниатюру из файла.
  - `image-viewer.ts` — Показывает картинку на весь экран для подробного просмотра.
  - `thoughts-block.ts` — Рисует раскрывающийся блок "💭 Мысли".
  - `message-menu.ts` — Выпадающее меню сообщения (⋮): удалить, копировать и другие действия. Сохранение картинки находится прямо на картинке.
  - `workspace-menu.ts` — Глобальное меню кнопки `☰`: новая вкладка, переходы по разделам приложения и Web UI 9Router. Открывается поверх всей страницы.
  - `toast.ts` — Всплывающие цветные уведомления внизу экрана.
  - `confirm.ts` — Всплывающее окно "Вы уверены?".
- **`services/`** — Переводчики. Они берут вашу команду (например, "удали чат") из интерфейса и передают её в двигатель (`src-tauri`). Один из них — `GraphService.ts` — отвечает за чтение и сохранение схем графов (открыть YAML, сохранить YAML).
- **`utils/`** — Вспомогательные инструменты:
  - `chat-dom.ts` — DOM-конструктор страницы чат-вкладки (`buildChatPage`): главная (main)
    с логотипом `logo.svg` + рейлом разделов, обычная чат-вкладка, iframe веб-вкладка
    (`buildWebviewPage`). Также `SharedChatControls` — общие слайдеры сэмплинга.
  - `model-options.ts` — Заполнение селектов моделей/агентов (`fillModelSelect`/`fillAgentSelect`,
    комбо 9Router).
  - `session-clipboard.ts` — Копирование сессии в буфер как Markdown.
- **`telemetry.ts`** — Отправка анонимных отчётов об ошибках. Следит за галочкой «Отправлять анонимные отчёты об ошибках» в настройках: если она выключена, ничего никуда не отправляется.
- **`store.ts`** — Общеприкладной стейт: вкладки (`tabs`/`activeTabId`), глобальный флаг
  обработки, каталоги (модели, агенты, комбо 9Router). Чат-стейт ВНЕ Store — живет в
  `ChatTabState` каждой вкладки.
- **`styles.css`** — Дизайн, цвета кнопок, темная и светлая темы.
- **`main.ts`** — Тонкий бутстраппер: создаёт TabController, разделы, студию агентов;
  регистрирует `initChatEventRouter()`; восстанавливает вкладки из конфига.

## ⚙️ Двигатель приложения: папка `src-tauri/`
Это "настольная" часть программы. Здесь настраиваются права программы в Windows и лежит сам код движка.

- **`capabilities/`** — Папка с разрешениями для программы. Файл `default.json` внутри нее говорит Windows: "Этой программе разрешено открывать системные окна сохранения файлов и запускать скрипты". Без этого защита компьютера блокировала бы программу.
- **`icons/`** — Картинки и иконки приложения (те, что вы видите на панели задач и на рабочем столе).
- **`mcp_servers/`** — "Руки" искусственного интеллекта. Это скрипты-инструменты, которые агенты могут запускать по своей инициативе:
  - `web_search.cjs` — Дает ИИ возможность гуглить (мульти-движковый поиск без API-ключей: DuckDuckGo, Brave, Startpage, Sogou, Baidu, Bing, Juejin, CSDN, Exa).
  - `searxng_search.cjs` — Мета-поиск через публичные инстансы SearXNG (без API-ключей): сам находит и кеширует рабочие инстансы из списка searx.space, умеет HTML-фолбэк, фильтры языка/времени и параллельный опрос.
  - `web_http.cjs` — Общий HTTP-слой для MCP-серверов (загрузка страниц, декомпрессия, защита от SSRF).
  - `docs_fetcher.cjs` — Чтение веб-страниц и статей (CSDN, Juejin, Linux.do, README с GitHub).
  - `youtube_mcp.cjs` — Дает ИИ возможность читать субтитры видео с YouTube.
  - `fs_read.cjs` / `fs_write.cjs` — Дают ИИ возможность читать и создавать файлы на вашем диске.
  - `deno_runner.ts` — "Песочница", где ИИ может безопасно запустить написанный им же программный код.
- **`src/`** — Исходный код самого двигателя (написан на языке Rust). Внутри него:
  - **`api/`** — Приемная. Ловит команды от интерфейса (`src/`) и передает их нужным отделам.
  - **`domain/`** — "Мозг". Здесь программа понимает логику агентов (кто кого должен вызвать по схеме, как склеить их ответы).
  - **`infra/`** — "Чернорабочие". Сохраняют чаты на диск, скачивают модели из интернета, загружают ИИ в память компьютера.
    - Папка `telemetry/` внутри неё — отправка анонимных отчётов об ошибках (например, если программа упала). Работает только если галочка в настройках включена.
- **`tauri.conf.json`** — Главный файл настроек программы (ее название "King Orch", версия, размеры окна при запуске).
- **`Cargo.toml`** — Список стройматериалов (библиотек), нужных для сборки двигателя.
- **`build.rs`** — Инструкция для компилятора, как именно собирать двигатель перед запуском.

## 📄 Отдельные файлы в корне проекта (вне папок)

- **`build.bat`** — Скрипт быстрой локальной сборки программы на вашем компьютере (тонкая обёртка над `tauri-build-toolkit`).
- **`release.bat`** — Скрипт для создания "чистового" установщика (файла `.exe`, который можно скинуть друзьям).
- **`generate_installer.bat`** — Еще один вариант создания установщика (обычно используется для авто-обновлений).
- **`test.bat`** — Скрипт для проверки, не сломали ли вы двигатель при изменении кода.
- **Каталог ИИ-моделей** (`models_catalog.json`) живёт в плагине `tauri-plugin-llama-engine` (SSOT) и компилируется в бэкенд через `include_str!`. Из него берется список моделей, когда вы открываете "Настройки -> Скачать новую модель". В корне репозитория дубликат не хранится.
- **`package.json`** — Список инструментов, нужных для работы графического интерфейса (Frontend).
- **`index.html`** — Тот самый файл-каркас, на котором рисуется весь графический интерфейс (как веб-страница).
- **`vite.config.ts` / `vitest.config.ts` / `tsconfig.json`** — Технические настройки для сборки и тестирования интерфейса.
