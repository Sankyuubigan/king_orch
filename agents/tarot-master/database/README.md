# База карт Таро (SSOT)

Единственный источник правды о картах для команды «Таролог». Любой номер карты
(0–77) превращается в данные карты только здесь — в `cards.json`. Ни тулы, ни
движок, ни промпты агентов не дублируют список карт.

## Состав

| Файл | Назначение |
|---|---|
| `cards.json` | Manifest: 78 записей, по одной на строку. Поля описаны ниже. |
| `cards/` | 78 изображений колоды Rider–Waite (1909), JPEG ~350px по широкой стороне. |

## Поля записи `cards.json`

- `id` — slug: `the_fool` … `the_world` для старших; `wands_ace`, `wands_02`…`wands_10`,
  `wands_page`, `wands_knight`, `wands_queen`, `wands_king` (аналогично `cups_`, `swords_`, `pentacles_`).
- `number` — 0–77, уникальный ключ для лукапа. Нумерация:
  0–21 — старшие арканы (порядок Уэйта: **8 = Сила, 11 = Справедливость**);
  22–35 — Жезлы, 36–49 — Кубки, 50–63 — Мечи, 64–77 — Пентакли;
  внутри масти: Туз → 02…10, затем Паж, Рыцарь, Королева, Король
  (Wands01 → 22, Wands11 → 32, Pents14 → 77).
- `name_en` / `name_ru` — названия карт.
- `arcana` — `major` | `wands` | `cups` | `swords` | `pentacles`.
- `rank` — для старших строка `"0"…"21"`, для младших `ace`, `02`…`10`, `page`, `knight`, `queen`, `king`.
- `keywords_ru` — 3–6 ключевых слов через запятую.
- `upright_ru` / `reversed_ru` — значения в прямом и перевёрнутом положении.
- `image_file` — имя файла в `cards/` (точное, без пути).

## Источники и лицензии

- **Изображения** — Wikimedia Commons, категория «Rider-Waite tarot deck»:
  `https://commons.wikimedia.org/wiki/Special:FilePath/<FILE>?width=350`.
  Колодa 1909 г., иллюстрации Памелы Колман Смит (†1951) — public domain
  (США: publication + 28 + 28 лет; Великобритания: 70 лет после смерти автора).
  Дата скачивания: 24–25.10.2026. Ограничение U.S. Games Systems касается только
  их редакции 1971 г. (рубашка/упаковка), не самих карт 1909 г.
  ⚠️ Сканы из metabismuth/tarot-json НЕ использовались («PD в США, но не в ЕС»).
- **Черновик английских текстов** — Tarotoo tarot-dataset
  (`https://github.com/Tarotoo-com/tarotoo-tarot-dataset`, файл `data/cards.json`),
  лицензия MIT. Нумерация датасета совпала с зафиксированной здесь (проверено
  скриптом 25.10.2026). Тексты переработаны в русские `upright_ru`/`reversed_ru`.
- **Русские значения карт** — рабочие формулировки, переработанные из PD-источников:
  A. E. Waite, «The Pictorial Key to the Tarot» (1911, public domain,
  archive.org identifiers `pictorialkeytota00arth` и др.). Современные
  русские книги по Таро не копировались (копирайт).
