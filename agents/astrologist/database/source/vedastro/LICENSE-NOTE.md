# Источник данных VedAstro — лицензия и атрибуция

- Проект-источник: **VedAstro**, https://github.com/VedAstro/VedAstro
  (файлы `Library/XMLData/HoroscopeDataList.xml` и `Library/XMLData/EventDataList.xml`,
  ветка master).
- Лицензия проекта VedAstro: **MIT** — переиспользование и модификация данных
  допустимы при сохранении уведомления об авторских правах и текста лицензии.
- Дата скачивания: **29.10.2026**.
- Тексты условий и результатов записей переведены на русский язык и переработаны
  в базу знаний астролога:
  - `database/yogas.md` — йоги (детектируемый набор);
  - `database/gochara.md` — транзиты от Луны (Gochara);
  - `database/dasha_rules.md` — правила периодов даш (DasaSpecialRules).
- Идентификаторы записей (Name) сохранены в заголовках секций как ссылки на
  источник. Исходные XML и промежуточные JSON (parsed_*, classified_*) лежат
  в этой папке.
