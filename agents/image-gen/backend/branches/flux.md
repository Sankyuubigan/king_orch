# База FLUX (FLUX.3 Klein)

Правила стека — инжектятся движком ТОЛЬКО при активном flux3-бандле
(`base=flux` в `[АКТИВНЫЙ БОНДЛ]`).

## Генерация (t2i)

Klein-дистиллят: 16 шагов, CFG 1.0, euler. Развёрнутый английский
промпт: субъект, композиция, ракурс, свет, стиль.

## Правка: адресация референсов словами

FLUX.3 Klein правит по референсам нативно (native), но метки `<imageN>`
для этого стека НЕ подтверждены — адресация ПО ПОРЯДКУ словами.

- Картинки адресуй описаниями по порядку из массива `source_image_ids`:
  the first image (холст), the second image (источник) и т.д. Пример:
  `Change the outfit of the person in the first image based on the outfit shown in the second image. Keep the face, pose, background and lighting of the first image completely unchanged.`
- Теги `<image1>`/`<image2>` НЕ вставляй — их подстановка движком для
  flux3 не подтверждена; файл обновится, если bench подтвердит теги.
- Стек держит до 10 референсов; роль каждой картинки проговаривай по
  порядковому номеру.

## Правка: замена лица

Нативный ref-edit: указывай на референс порядковым словом, не описывай
лицо признаками словами — иначе модель перегенерирует лицо и разрушит
сходство (то же правило, что у Qwen, но словами вместо тегов).

## Лоры базы FLUX

Лоры лежат в `image_loras\flux\`; взрослый контент на FLUX-бандле
закрывается лорами ИМЕННО этой базы (фильтра в открытом пайплайне нет,
но база недообучена на NSFW — рычаг тот же, что у Qwen: LoRA).

Конкретные стемы и стартовые силы вписываются сюда только по факту
валидации лоры на этом стеке. Если в каталоге LoRA твоего контекста нет
ни одной лоры базы flux — вызывай БЕЗ `lora` и скажи пользователю, что
лоры для этой базы пока не добавлены.
