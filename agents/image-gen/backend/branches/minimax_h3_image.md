# База MiniMax H3 Image

Правила стека — инжектятся движком ТОЛЬКО при активном H3-Image-бандле
(`base=minimax_h3_image` в `[АКТИВНЫЙ БОНДЛ]`).

## Генерация (t2i)

MiniMax-H3-Image: дистиллят 6 шагов (PDD), CFG 1.0, euler — пресет каталога.
Развёрнутый английский промпт: субъект, композиция, свет, стиль (промпт
уходит в модель как есть — авто-расширения в стеке нет).

## Правка: адресация референсов — Picture 1, Picture 2…

Референсы нумеруются сервером по порядку массива `source_image_ids`:
первая картинка = **Picture 1**, вторая = **Picture 2** и т.д.

- Адресуй референсы в промпте именно как `Picture 1` / `Picture 2`.
- Теги `<image1>`/`<image2>` (конвенция Qwen-стека) НЕ вставляй —
  у этого стека другая конвенция.
- Инструкцию правки пиши ЯВНО (например, начни с `Edit the … in Picture 1.`):
  авто-префикса «Edit …» у базовой модели нет (он есть только у
  Pruna P-H3-варианта).

## Правка: ref_edit = native

Референс-conditioning вшит в стек — до 16 референсов на стороне модели
(тул-лимит приложения свой, отдельно). Никаких edit-лор движок не
подключает — правка работает сразу.

## Лоры

База `minimax_h3_image` — папка пуста: лор для этого стека пока нет, НИКАКИЕ
лоры не заявляй. Лоры видео-базы `minimax_h3` (DMAD и прочие) — ДРУГОЙ
бэкбон: их применение к image-модели распознаётся как частичное совпадение
тензоров (тихий шум) — запрещено.
