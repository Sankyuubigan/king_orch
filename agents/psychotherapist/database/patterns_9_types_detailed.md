## КРИТИЧЕСКОЕ ПРАВИЛО МАТЕМАТИКИ ЭТАЖЕЙ (ЧИТАТЬ ПЕРЕД АНАЛИЗОМ)
У реального человека в конкретной проблеме **Этаж 0 `{1, 4, 7}`**, **Этаж -1 `{2, 5, 8}`** и **Этаж -2 `{3, 6, 9}`** **ВСЕГДА ИМЕЮТ РАЗНЫЕ ТИПЫ**, которые переходят друг в друга по формуле `conversions_patterns.md`:
*   **Спуск вниз (к причине / ядру травмы):** `Тип Этажа 0` → (через Безопасность) → `Тип Этажа -1` → (через Безопасность) → `Тип Этажа -2 (Ядро)`.
*   **Подъем вверх (к следствию / симптому):** `Тип Этажа -2 (Ядро)` → (через Стресс) → `Тип Этажа -1` → (через Стресс) → `Тип Этажа 0`.

**Как использовать этот справочник:**
В карточках ниже для каждого из 9 типов расписано, как этот тип выглядит, **если он оказался на Этаже -2**, **если он оказался на Этаже -1**, и **если он оказался на Этаже 0**.
1. Возьми элементы клиента `{1, 4, 7}` и найди по блокам `ЭТАЖ 0` ниже, какой тип (T0) проявляется на поверхности.
2. Возьми элементы клиента `{2, 5, 8}` и найди по блокам `ЭТАЖ -1` ниже, какой тип (T-1) проявляется на среднем этаже.
3. Возьми элементы клиента `{3, 6, 9}` и найди по блокам `ЭТАЖ -2` ниже, какой тип (T-2) лежит в триаде травмы.
4. Проверь сцепку через `conversions_patterns.md`: T0 → (безопасность) → T-1 → (безопасность) → T-2. Искомый результат твоей работы — тип T-2 (Триада травмы `{3, 6, 9}`).
