=========================================
ИНСТРУКЦИЯ (СТРОГО ДЛЯ ВЫПОЛНЕНИЯ):
=========================================

Твоя задача — вычислить базовый паттерн (тип 1–9) **Триады Травмы (Этаж -2: элементы 3, 6, 9)**.

У реального человека каждый из трех этажей невроза имеет СВОЙ отдельный тип, связанный с соседними этажами по формуле переходов (`conversions_patterns.md`):
*   **Спуск вниз к причине (от симптома к ядру травмы):** идет через переходы **Безопасности** (`Тип Этажа 0` -> Безопасность -> `Тип Этажа -1` -> Безопасность -> `Тип Этажа -2`).
*   **Подъем вверх к следствию (от ядра травмы к симптому):** идет через переходы **Стресса** (`Тип Этажа -2` -> Стресс -> `Тип Этажа -1` -> Стресс -> `Тип Этажа 0`).

**Алгоритм твоего разбора внутри `<think>`:**
1. **Анализ Этажа 0 (Триада `{1, 4, 7}`):** Сопоставь элементы 1, 4, 7 клиента с блоками `ЭТАЖ 0` из `external_contour_9_patterns.md` и определи тип Этажа 0.
2. **Анализ Этажа -1 (Триада `{2, 5, 8}`):** Сопоставь элементы 2, 5, 8 клиента с блоками `ЭТАЖ -1` из `external_contour_9_patterns.md` и определи тип Этажа -1.
3. **Анализ Этажа -2 (Триада травмы `{3, 6, 9}`):** Сопоставь элементы 3, 6, 9 клиента с блоками `ЭТАЖ -2` из `external_contour_9_patterns.md` и определи кандидатов на базовый тип Триады Травмы.
4. **Математическая верификация по `conversions_patterns.md`:** Сложи все три этажа в единую цепь переходов (`Этаж 0` --безопасность--> `Этаж -1` --безопасность--> `Этаж -2` И `Этаж -2` --стресс--> `Этаж -1` --стресс--> `Этаж 0`) и зафиксируй точный номер типа **Этажа -2 (элементы 3, 6, 9)**.

**[СОХРАНЕНИЕ РЕЗУЛЬТАТА (нативный вызов инструмента)]**
Итог твоего анализа — ОДИН номер базового типа паттерна (1–9), определённый по триаде травмы (элементы 3, 6, 9). Пайплайн читает по этому номеру секцию лечебной базы `## {номер}`, поэтому номер обязан быть машинным, а не прозой.

Грамматика автоматически заставляет тебя сначала написать рассуждения в `<think>...</think>`, а ТОЛЬКО ПОТОМ JSON. Используй это: в `<think>` выпиши весь разбор по 4 шагам выше. ВАЖНО: теги вида `<что-угодно>` и символ `<` внутри `<think>` использовать НЕЛЬЗЯ — грамматика запрещает символ `<`. Пиши обычным текстом с заголовками, без угловых скобок и стрелок со скобками.

ПОСЛЕ `</think>` вызови `emit_signal` с `key="pattern_type"` и `value` = строка-цифра базового типа:
- `"1"` .. `"9"` — номер паттерна триады травмы (Этажа -2).
