## 1.1. AMD Token Lab — крупный одноразовый грант без карты и телефона

**[ПРОВЕРЕНО 2026-11-13..21]** OpenAI- и Anthropic-совместимый API: `https://api.tokenlab.amd.com/v1` (ключ `tl-...`). Вход через бесплатную `https://developer.amd.com/ai-developer-program/`, далее выдача ключа на `https://notebooks.amd.com/tokenlab`.
- **Карта и телефон НЕ нужны** — только email. *(Регистрация с РФ IP `[НЕ ПРОВЕРЕНО]` — заходить через VPN.)*
- **Тариф — ОДНОРАЗОВЫЙ грант:** 5–10 поинтов на 30 дней (+ 1 продление на 15 дней и кнопка дозапроса при остатке ≤2 pts), **20 RPM**.
- **Модели и реальный объём (на 10 поинтов):**
  - **`DeepSeek-V4.1-Flash-1017`** (0.28 pts/1M in, 0.56/1M out) → **~35M входных токенов** (~15–20M реального кодинга).

  - **`Qwen3.8-27B`**, **`Gemma-4-31B-IT`** (262K ctx, 0.035/0.07) → **~285M входных токенов**.
  - *(Живой список проверять через `/v1/models` — `GLM-5.3-Flash` в ноябрьском каталоге отсутствовала.)*
- **Привязка:** к аккаунту/ключу. Мультиакк по почтам `[НЕ ПРОВЕРЕНО]` (при работе: `~35M input × N акков`).

## 2.6. OpenCode v2 Free (`opencode.ai`) — ПРИОРИТЕТ 4 (самый низ!)

**[ЛИЧНО + ПРОВЕРЕНО 2026-11-21..24]**
- **Почему неюзабельно для кодинга:**
  1. **Нищая общая квота:** в OpenCode v2 все бесплатные модели сидят на **общем скрытом глобальном лимите** — квота кончается прямо на 1-й задаче `[ЛИЧНО]`, переключение на другую бесплатную модель лимит **не сбрасывает**. На общем VPN лимит может быть выжжен чужим трафиком.
  2. **OpenCode v1 (0.x/1.x)** вообще потерял поддержку free-моделей (нужен ручной апдейт на v2).
  3. **Скрытые stealth-подмены:** `Big Pickle` — официально подтверждённая stealth-модель OpenCode (подменяется под капотом, обучается на коде) → нестабильна, портит код. `glm-5.3-flash-free` выбыла из каталога по проверке 21.11.2026.
  4. **Жёсткий антифрод по IP** — на 1 IP мультиаккаунтинг ведёт к бану.

# РАЗДЕЛ 3. КРИПТО-ДЕПОЗИТНЫЕ ШЛЮЗЫ (несгораемый депозит)

## 3.1. OpenRouter (`https://openrouter.ai/api/v1`) — рабочий резерв, не топовый

**[ДОКИ, перепроверено 2026-11-24]**
- **Без депозита (0 кредитов):** всего **50 RPD** на все `:free` (нищий лимит).
- **С несгораемым крипто-депозитом ($10 в USDC):** баланс **не тратится** на `:free` модели, лимит навсегда поднимается до **1 000 RPD** (20 RPM). Вписывается в обновлённый профиль пользователя.
- **Почему НЕ топовый:** политика блоков РФ IP (обязателен Vercel-релей США), строгий тотальный запрет мультиакка ToS §7.3 (риск бана по IP), а пул и стабильность `:free`-провайдеров постоянно скачут.

*(**AIHubMix** тоже принимает $1 USDC, но даёт всего 100 RPD / 1M токенов/день суммарно → перенесён в Раздел 5 как нищий лимит.)*

# РАЗДЕЛ 4. ПРЯМЫЕ API СО СЛАБЕЕ МОДЕЛЯМИ (Приоритет 3 — резервы и мультиакк)

## 4.1. Groq — быстрый мультиакк-резерв (Категория A)

**[ДОКАЗАНО + ПРОВЕРЕНО 2026-11-01]** Карта и телефон НЕ нужны. Лимит **на организацию** → мультиаккаунтинг работает линейно (`TPD × N аккаунтов`). Скорость 300–600 tok/s. **Cached tokens не тратят лимит** [ДОКИ].
- **Главный ограничитель — TPD, а не RPD:**
  - `openai/gpt-oss-120b` / `gpt-oss-20b`: 30 RPM, 1 000 RPD, **200K TPD** (при 2K/шаг = 100 шагов/день на акк).
  - `llama-3.1-8b-instant`: 30 RPM, 14 400 RPD, **500K TPD**.
  - `llama-3.3-70b-versatile`: 30 RPM, 1 000 RPD, **100K TPD**.
  - `qwen/qwen3.8-27b` (заменил `qwen3.6-27b`), `minimaxai/minimax-m2.7` (preview): 30 RPM, 1 000 RPD.
  - **Удалены из Groq:** Llama-4, Kimi, GLM, DeepSeek, `groq/compound*`.
- Квирк: `console.groq.com` отдаёт 403 прямым curl/fetch — проверять через Wayback. В сложном агентском кодинге слабее `GLM-5.3-Flash`.

**[ДОКИ + ПРОВЕРЕНО 2026-11-01]** Карта не нужна, лимит **на аккаунт** (`10 000 нейронов/сутки × N аккаунтов`, сброс 00:00 UTC), **300 RPM**, суточного RPD нет.

# МЕТОДОЛОГИЯ: ГДЕ ЖИВУТ IP-ЛИМИТЫ

Ни один провайдер не пишет в тарифах «мы ограничиваем по IP»: тарифные квоты (L7) привязаны к Account/Org/Project ID, а **IP-лимит живёт на edge-уровне (Cloudflare, AWS WAF, Akamai)** как антифрод-эвристика.

- **Практический вывод для Vercel-релея:** несколько ключей с разумными задержками работают раздельно, но **десятки параллельных воркеров с одного IP вызовут 403 / CAPTCHA на весь релей сразу**. Обязательно ограничивай параллелизм и держи fallback-роутер.
